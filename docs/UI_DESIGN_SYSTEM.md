# Enterprise Aurora UI design system

The interface deliberately avoids the previous gold/grey portfolio aesthetic and the AI-greetings visual language. It uses a hospitality operations theme: deep midnight/navy surfaces, cyan/mint operational accents, restrained violet depth, glass layers, animated aurora glows and role-specific workspace cards.

Key principles:
- Dense enterprise information remains readable; motion is subtle and task-oriented.
- Sidebar navigation is grouped by operational domain and filtered by role.
- Dashboard begins with a role-specific command workspace, not a generic admin landing page.
- Responsive layouts preserve front-desk/tablet usability.
- Hover, focus, active-route, notification and card-rise animations are CSS-only and lightweight.
- Client brand/company/property names remain configurable rather than hard-coded.
