# Screen map mapped to client specification

## Public / guest
- `/book` Direct Booking Engine: availability, room/rate selection, add-ons, guest details, taxes, payment preference, confirmation.
- `/guest` Guest Application: booking lookup, stay details, folio, payment, housekeeping/restaurant/spa/transport requests.

## Dedicated staff screens
- `/dashboard` Executive Dashboard
- `/reservations` Reservation Management
- `/calendar` Visual Tape Chart
- `/rooms` Room Management
- `/folios` Check-out / Folio / Payments
- `/housekeeping` Housekeeping operations
- `/revenue-distribution` Rate Quote / Revenue / CRS / Channel Manager / Groups
- `/guest-experience` CRM / loyalty / service / journey / upsell workspace
- `/pos` Restaurant POS / KDS workflow
- `/reports` Reports & Analytics
- `/ai` AI Management Assistant
- `/approvals` Approval Workflow
- `/audit` Audit Trail
- `/admin` SaaS / property / user administration

## Enterprise module screens via `/m/:module`
Rate plans, CRS allotments, booking engine content, channel mappings, loyalty, service requests, guest journeys, upsell offers, laundry, linen, minibar, kitchen tickets, spa, banquet/events, conference rooms, inventory, purchasing, suppliers, A/R, A/P, night audit records, cashier shifts, corporate accounts, travel agents, maintenance, preventive maintenance, assets, transport, lost & found, incidents, employees, shifts, attendance, documents, forecasts, currencies, translations, taxes, integrations, webhooks, door locks, IoT, energy, subscriptions, plans, feature flags, backups and integration logs.
